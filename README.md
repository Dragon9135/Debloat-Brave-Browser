# **Debloat** ![Brave Browser](https://brave.com/favicon.ico)
Debloat [Brave Browser](https://brave.com/) using only a Registry file, without any programs or third-party tools.

For a smoother process, make sure the Brave Browser is completely closed. Use Task Manager to check whether it is still running in the background. After applying the changes, you can visit `brave://policy` to check if everything is working correctly.
